# Margin Wiki

Margin is a local-first personal finance tracker. The first planning release, `v0.1.0`, is published; the current `v0.2.0` core-tracking slice is in final local release preparation. This Wiki is the long-form project reference; the repository README is the concise entry point and `project/` contains the working roadmap and task briefs.
