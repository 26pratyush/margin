# MARGIN-005 — Create application shell and design foundation

## Goal

Create the first navigable local app shell with the visual language for Margin.

## Design direction

- Deep charcoal background.
- Warm, readable text.
- One restrained accent color.
- Clear hierarchy and compact transaction rows.
- Subtle borders and purposeful spacing.
- No neon gradients, excessive glass cards, or decorative dashboard clutter.

## Initial surfaces

- Home/dashboard shell.
- Transactions shell.
- Insights shell.
- Commitments shell.
- Settings shell.

## Acceptance criteria

- Navigation is understandable without implementation knowledge.
- Empty states explain what the user can do next.
- Design tokens are centralized enough to evolve.
- The shell works with synthetic data and without data.
