# MARGIN-009 — Create static product-site foundation

## Goal

Create a static, portfolio-quality website that explains Margin without running the finance application publicly.

## Sections

- Product positioning.
- Problem and intended user.
- Core workflows.
- Screenshots.
- Local-first architecture.
- Design principles.
- Roadmap and GitHub links.
- Privacy boundary.

## Acceptance criteria

- The site builds independently from `site/`.
- It contains no API, database, or personal financial data.
- Screenshots use synthetic or redacted values.
- The GitHub Pages deployment instructions are documented.
- The site links back to the repository and relevant project resources.
